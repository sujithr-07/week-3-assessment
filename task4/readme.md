
| BERT (Encoder)                                                    | GPT (Decoder)                                                  |
| ----------------------------------------------------------------- | -------------------------------------------------------------- |
| Uses encoder-only Transformer architecture.                       | Uses decoder-only Transformer architecture.                    |
| Uses bidirectional attention to understand context.               | Uses causal attention to predict the next token.               |
| Best suited for text classification and understanding.            | Best suited for text generation and conversational tasks.      |
| Commonly used for sentiment analysis, NER and question answering. | Commonly used for chatbots, text generation and summarization. |
| Learns contextual representations of input text.                  | Generates text one token at a time.                            |
